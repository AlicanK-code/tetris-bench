# Term-level replay variants

The 23 functions behind
[the-best-revision-was-a-repair.md](../../../docs/findings/the-best-revision-was-a-repair.md).
None was written by a model: each is a **reconstruction** of one of two saved
functions with exactly one thing changed, so the effect of that one thing can be
measured. Generated by `analysis/reweighting.py`, which replays them on the same
held-out seeds (`1000-1009`) every other result here uses.

## `30b-chain1-{dead,live}-{old,new}-{tie,notie}.py`

The 2x2x2 crossing of what `qwen3-30b` chain 1's revision changed between
iteration 0 and iteration 5:

- **heights** — `dead` is iteration 0's block, which scans up from row 19 and
  stops at the first filled cell, so every height is `19 - 19 = 0` on a board
  resting on the floor. `live` is iteration 5's, which scans down from row 0.
- **weights** — `old` is `lines*100 - holes*20 - max_height*5 - bumpiness*1`,
  `new` is `lines*10 - holes*350 - max_height*15 - bumpiness*35`.
- **tie** — whether iteration 0's trailing `unique_term` is present.

Two cells reconstruct the saved functions and are the check on all the others:

| cell | should score | the original |
|---|---:|---|
| `dead-old-tie` | **41.55** | [`30b-pilot/functions/qwen3-30b-chain1-iter0.py`](../30b-pilot/functions/) |
| `live-new-notie` | **50.19** | [`30b-pilot/functions/qwen3-30b-chain1-iter5.py`](../30b-pilot/functions/) |

One cosmetic difference from the originals: the template always writes
`bumpiness * 1` where iteration 0 wrote a bare `bumpiness`. Same arithmetic, and
the scores match exactly.

## `30b-chain1-tiebreak-*.py`

Five trailing terms over iteration 0's broken function, separating *breaking a
tie* from the **direction** the tie is broken in. `row` is the top row of the
piece's bounding box and row 0 is the top, so a larger row is a lower placement:
`row-low` prefers low, `row-high` is the same term negated, and `column-only`
breaks ties while carrying no height information at all. 15.29 with no term,
42.88 preferring low, 13.92 preferring high.

## `8b-chain3-from-it{0,5}-*.py`

`qwen3-8b` chain 3 changed only its weights, so these walk one weight at a time
between iteration 0's `(100, 1, 0.5, 0.1)` and iteration 5's
`(50, 100, 150, 150)`. The `baseline` file in each direction is the unmodified
endpoint; each other file moves exactly one of `lines`, `holes`, `max_h`,
`unevenness`.

Iteration 5's `bottom_empty` term is omitted from all of them. It counts
all-empty rows upward from row 19 and stops at the first non-empty one, so it is
zero on any board with anything resting on the floor.

## Reading them

These are reconstructions, so the normal warning applies with an extra edge:
**read them, do not import them.** They are generated from strings in
`analysis/reweighting.py` and executed only inside the sandbox described in the
top-level README, exactly as the model-written originals are.
